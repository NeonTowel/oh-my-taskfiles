# Git Commit Practices

- Commit changes to Git often, after each logical group of edits. Examples:
  - after each successfully completed task.
  - after each successfully completed todo.
  - after each successfully completed step of a Milestone in a Exec Plan.
- Invoke `git-commit` skill once in session. Refresh instructions if session decay removes skill instructions from session context.
- DO NOT push changes to remote.
- DO NOT revert, or restore unless user explicitly approves.
