# Continuous Improvement

After finishing a `task`, `step` or a `milestone`, evaluate if `Extractable Knowledge` emerged:

- `Non-obvious solution` discovered through investigation?
- `Workaround` for `unexpected behavior`?
- `Project-specific pattern` learned?
- `Error` required debugging to resolve?

If `yes`:

- Invoke `self-improvement` skill to log to project root `.learnings/`.

If `high-value` (recurring, broadly applicable):

- Consider creating a new skill for recurring learnings
- See [the extract skill guide](references/extract-skill.md) for instructions.
